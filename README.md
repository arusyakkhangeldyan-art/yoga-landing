# Yoga with Arika Landing Page

Modern single-page landing site for a premium yoga studio built with Next.js
(App Router) and Tailwind CSS.

## Tech Stack

- Next.js `16` (App Router)
- React `19`
- Tailwind CSS `4`
- TypeScript + ESLint

## Project Structure

```txt
app/
  components/
    section-title.tsx
  data/
    content.ts
  globals.css
  layout.tsx
  page.tsx
```

## Included Sections

1. Hero section with primary CTA (`Book a class`)
2. About section
3. Services (Hatha, Vinyasa, Yin)
4. Pricing (3 plans)
5. Testimonials
6. FAQ
7. Contact form

## Design Direction

- Minimalist and calm visual language
- Beige + white + soft green palette
- Premium card-based layout with gentle shadows
- Fully responsive for mobile, tablet, and desktop

## Local Development

Install dependencies and run:

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` - start local dev server
- `npm run build` - production build
- `npm run start` - run production server
- `npm run lint` - run ESLint
